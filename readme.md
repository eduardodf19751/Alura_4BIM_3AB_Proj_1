# 🌊 Flashcards: Mitos e Verdades sobre a Vida Marinha

Projeto interativo de Flashcards desenvolvido como parte do conteúdo prático do **4º Bimestre da Alura** (Pensamento Computacional / Front-end). O objetivo principal é fixar conceitos de estruturação web, estilização avançada e manipulação do DOM.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página e dos cartões.
* **CSS3:** Estilização moderna com variáveis CSS, Flexbox para responsividade e propriedades tridimensionais (`perspective`, `transform-style`, `backface-visibility`) para o efeito de rotação.
* **JavaScript:** Manipulação de classes (`classList.toggle`) vinculada a ouvintes de eventos (`addEventListener`) para dar interatividade aos cards.

## 🧠 O que o projeto exercita?

1. **Efeito Flip 3D Puro:** Rotação suave dos cartões em um eixo tridimensional sem a necessidade de bibliotecas externas.
2. **Design Temático:** Identidade visual inspirada nas profundezas do oceano, utilizando cores contrastantes para destacar as respostas corretas (*Mitos* em vermelho, *Verdades* em verde).
3. **Código Limpo:** JavaScript enxuto que funciona dinamicamente para qualquer quantidade de cartões adicionados ao contêiner.

## 📂 Como executar o projeto localmente

1. Faça o download ou clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador.
4. Clique em qualquer um dos cartões para virá-lo e descobrir se a afirmação é um mito ou uma verdade!
